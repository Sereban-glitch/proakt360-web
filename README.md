# ProAkt 360 (v2.2) — Кабинет строителя & Telegram Mini App

Актуальная версия исходного кода веб-приложения и Telegram-бота «ПрорАКТ 360» (версия v2.2), соответствующая работающему продакшн-серверу (`/opt/proakt-360`, сервис `proakt-360.service`, Telegram-бот `@ProAktSmetaBot`).

Ветка: `v2.2-server-sync`

---

## Что изменилось по сравнению со снапшотом V2

1. **Telegram Webhook и Mini App:**
   - Добавлен роут вебхука `/api/telegram/webhook` с обработкой `/start` и `/app` и отправкой WebApp-кнопки прямого перехода.
   - Исправлена маршрутизация при запуске из Telegram Desktop/Mobile (`/?v=2.2`), устранена ошибка «Экран не найден».
2. **Безопасная аутентификация (Fail-Closed):**
   - Добавлена первичная инициализация пароля мастера локально: `npm run setup:password` (интерактивно или через `--stdin`).
   - Пока пароль не задан, API отвечает `503`, удалённая настройка запрещена.
   - Поддержка валидации сессии через `x-telegram-init-data` (HMAC SHA-256) и `Secure`/`SameSite=Lax` cookie.
3. **Автотесты и верификация:**
   - Добавлен скрипт сквозного тестирования `scripts/e2e-check.ts` (проверяет весь цикл: смета → акты → превышения → оплаты → экспорт).
   - Добавлен тест восстановления БД `scripts/test-restore.ts`.
4. **Экспорт и каталоги:**
   - Реализован экспорт смет и актов в XLSX и текст.
   - Импорт расценок, валидация единиц измерения и строк сметы.
5. **Чистый Node.js / npm runtime:**
   - Сборка и запуск работают на Node.js (без обязательной привязки к Bun).
   - Настоящая распакованная структура репозитория (`src/`, `prisma/`, `public/`, `scripts/`).

---

## Санитизация данных

Репозиторий строго очищен от чувствительных данных:
- Базы данных (`*.db`, `custom.db`) и клиентские фотографии (`uploads/`) исключены из репозитория.
- Приватные материалы и данные заказчиков (`seed_vitaliy.ts`) исключены.
- Секретные токены и пароли удалены; в коде используются переменные окружения `TELEGRAM_BOT_TOKEN`, `DATABASE_URL` и `WEBAPP_URL`.

---

## Быстрый запуск

```bash
npm install
cp .env.example .env
npx prisma generate
npx prisma db push
npm run db:seed:node          # синтетические демо-данные (без приватных материалов)
npm run setup:password        # задать локальный пароль мастера
npm run dev                   # http://localhost:3000
```

Production-запуск:
```bash
npm run build
npm run start
```
